# SheCan

Women's empowerment app built with Expo and React Native.

## Tech Stack

- Expo SDK 56
- React Native 0.85.3
- React 19.2.3
- Supabase (backend)
- React Navigation v7
- TypeScript

## Getting Started

```bash
npm install
npx expo start
```

## Scripts

- `npm start` — Start Expo dev server
- `npm run android` — Start for Android
- `npm run ios` — Start for iOS
- `npm run web` — Start for web
- `npm test` — Run tests

## Project Structure

```
SheCan/
  src/
    types/        # TypeScript type definitions
    constants/    # Theme constants (colors, fonts, spacing)
  __tests__/      # Test files
```
